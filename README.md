# Apotheosis Docs

[Перейти на сайт.](https://arcaness14.github.io/apotheosis-docs/)

Дизайн-документ и техническая документация средневекового билда Space Station 14.

## Локальный запуск

```bash
pip install -r requirements.txt
mkdocs serve
```

Сайт автоматически публикуется на GitHub Pages после обновления ветки.

Подробности о структуре и правилах: [docs/contributing/writing.md](docs/contributing/writing.md).

## Лицензирование

Содержимое репозитория распространяется на условиях двух лицензий в зависимости от типа материала.

### Документация - CC BY-SA 4.0

Тексты в каталоге [`docs/`](docs/), дизайн-документ, техническая документация и содержимое `README.md` распространяются на условиях [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/deed.ru) (CC BY-SA 4.0), если рядом с конкретным материалом не указано иное.

### Код - MIT

Скрипты, HTML-шаблоны, таблицы стилей, JavaScript и самостоятельные фрагменты программного кода в репозитории распространяются на условиях [лицензии MIT](https://opensource.org/license/mit).

При копировании или распространении существенных частей такого кода необходимо сохранить уведомление об авторских правах и текст лицензии MIT.

### Исключения

Лицензии распространяются только на материалы, права на которые принадлежат авторам проекта "Апофеозис". Они не предоставляют прав на товарные знаки, исходный код или иные материалы Space Station 14 и других третьих лиц. Материалы с отдельным уведомлением сохраняют указанную в нём лицензию и авторство.
