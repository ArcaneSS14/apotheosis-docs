# Apotheosis Docs

[Перейти на сайт.](https://vecortys.github.io/apotheosis-docs/)

Дизайн-документ и техническая документация средневекового билда Space Station 14.

## Локальный запуск

```bash
pip install -r requirements.txt
mkdocs serve
```

Сайт автоматически публикуется на GitHub Pages после обновления ветки.

Подробности о структуре и правилах: [docs/contributing/writing.md](docs/contributing/writing.md).
